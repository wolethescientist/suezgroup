# Sector photographs

One frame per operating company, used by the cycling stage behind the home
hero, the about hero and the closing band (`lib/sectors.ts` →
`components/sector-stage.tsx`).

All five are **library photographs from Pexels** (free for commercial use, no
attribution required — recorded here anyway), exported at 3840 × 2160.

**The rule these obey:** a caption describes the *practice*, never possession.
No frame here claims to be a Suez asset, and none ever should. Replacing one
with a real shot is the whole point — drop the file in at 3840 × 2160 (16:9,
subject off-centre right, since hero copy sits left), point `photo` at it in
`lib/sectors.ts`, and rewrite the `alt` in the first person.
